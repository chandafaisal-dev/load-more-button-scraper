# Load More Button Scraper

A Python Selenium project that automatically clicks the **Load More** button until all products are loaded and extracts product names and prices.

## Features

- Automatically clicks the Load More button
- Extracts product names
- Extracts product prices
- Saves data into CSV
- Uses Selenium WebDriver

## Technologies Used

- Python
- Selenium
- Pandas
- WebDriver Manager

## Output

load_more_products.csv
